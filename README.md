# WSL — Workspace Launcher

현재 화면의 창 배치(실행 경로 · 모니터 · 좌표)를 스냅샷으로 저장하고, 원클릭/단축키로 **실행부터 배치까지 무인으로** 복원하는 Windows 데스크톱 유틸리티입니다.

## 설치

[**Releases**](../../releases/latest) 에서 `WSL-win-Setup.exe` 를 내려받아 실행하세요.

- 관리자 권한 없이 사용자 폴더(`%LocalAppData%\WSL`)에 설치되며, 바탕화면 · 시작 메뉴 바로가기가 만들어집니다.
- .NET 런타임이 포함되어 있어 별도 설치가 필요 없습니다.
- **자동 업데이트**: 실행 중 새 버전을 백그라운드로 받아 두고, 트레이 알림을 클릭하면 즉시 · 그냥 두면 프로그램 종료 시 자동 적용됩니다. 하단의 **업데이트 확인** 버튼으로 수동 확인도 가능합니다.
- 제거: Windows 설정 → 앱 → WSL 제거 (저장한 프로필은 `%APPDATA%\WorkspaceLauncher` 에 남습니다)

## 사용법

1. 평소처럼 모니터에 프로그램 · 폴더 · 문서 · 브라우저를 배치
2. **[📸 현재 레이아웃 저장]** → 저장할 창 체크 → 이름 입력
3. 프로필에 단축키 지정 (예: `Ctrl+Alt+1`) — 단축키 칸 클릭 후 조합 입력, Backspace 로 삭제
4. 적용: **▶ 적용** 버튼 / 프로필 더블클릭 / 트레이 우클릭 메뉴 / 전역 단축키 / 바탕화면 바로가기

## 기능

| 기능 | 설명 |
|---|---|
| 스냅샷 캡처 | 실행 중인 창의 프로세스 경로, 창 제목, 모니터 번호, 보이는 영역 좌표, 최대화/최소화 상태 자동 수집 |
| 만능 타겟 | 프로그램(.exe/.lnk/`shell:AppsFolder\…`) · 폴더(탐색기) · 파일 · URL(브라우저 지정, `--new-window`) · 창만 배치 |
| 문서 파일 자동 인식 | 엑셀·워드·파워포인트·한글·메모장·PDF 등은 **열려 있는 파일 경로**를 저장 → 복원 시 그 파일을 같은 프로그램으로 열어 배치. OneDrive/SharePoint 문서는 로컬 동기화 경로로 변환 |
| 중복 방지 | 이미 열린 창은 새로 실행하지 않고 HWND 만 찾아 이동. 같은 프로그램 창이 여러 개면 제목 유사도로 1:1 매칭 |
| 실행 대기 | 실행 후 새 창(HWND)이 뜰 때까지 폴링 → 배치 → 잠시 후 재보정 (스플래시 교체 · 앱의 자체 위치 복원 대응) |
| 테두리 보정 | `DwmGetWindowAttribute(EXTENDED_FRAME_BOUNDS)` 로 보이지 않는 테두리(~7px)를 계산해 픽셀 단위로 정확히 맞춤 |
| 모니터 환경 감지 | 독 연결/해제 시 맞는 프로필을 알림으로 추천하거나 자동 전환. 해상도가 달라지면 상대 위치·비율로 변환 |
| Windows 시작 시 실행 | 시작 시 적용할 레이아웃과 대기 시간 선택 |
| 트레이 / 단축키 | 트레이 상주, 우클릭으로 프로필 적용, 전역 단축키 |
| 기타 | 바탕화면 바로가기(`--apply "프로필명"`), 다시 캡처(입력한 URL·인자 유지), 선택 항목만 적용, 현재 창 위치로 갱신 |

### 항목 편집 팁

- **URL 유형**: 브라우저는 현재 URL 을 알 수 없으므로 `대상` 칸에 URL 을 입력하세요. 크롬 프로필은 `실행 인자`에 `--profile-directory="Profile 1"`.
- **제목 포함**: 같은 프로그램 창이 여러 개일 때 특정 창만 잡도록 제목 일부를 지정.
- **지연(ms)**: 무거운 프로그램 실행 전 대기 시간.

### 제한 사항

- 관리자 권한으로 실행된 창은 WSL 도 관리자 권한이어야 이동 가능 (Windows UIPI 정책)
- Windows 11 탐색기가 "새 탭으로 열기" 설정이면 폴더가 기존 창의 탭으로 열릴 수 있음
- UWP 앱(계산기, 설정 등)은 `창만 배치`로 저장됨. 실행까지 하려면 대상에 `shell:AppsFolder\<AppID>` 입력

## 개발 · 배포

C# / WPF / .NET 10, 설치·업데이트는 [Velopack](https://velopack.io).

```powershell
# 빌드
dotnet build WorkspaceLauncher

# 새 버전 배포 — 버전 반영·태그·빌드·설치 패키지 생성·GitHub Release 업로드까지 한 번에 (gh 로그인 필요)
.\release.ps1 1.0.1
```

설치된 WSL 은 새 Release 를 감지해 스스로 업데이트합니다.

데이터: `%APPDATA%\WorkspaceLauncher\profiles.json` · 오류 로그: 같은 폴더의 `error.log`
